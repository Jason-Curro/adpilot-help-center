# Maintaining AdPilot Help Center

The English and Italian guides are the canonical public
documentation for AdPilot.

## Updating documentation

1. Verify current product behavior.
2. Update the English articles.
3. Update the corresponding Italian articles.
4. Keep article IDs consistent across languages.
5. Update JSON metadata when necessary.
6. Regenerate llms.txt and llms-full.txt.
7. Validate links and Markdown formatting.
8. Review all content before publication.

## Publication requirements

Documentation must not contain:

- Application source code
- Credentials or API keys
- Internal endpoints
- Private infrastructure details
- Customer information
- Internal security findings

Technical details must be translated into clear,
beginner-friendly instructions.
